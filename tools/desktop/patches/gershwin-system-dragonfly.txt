FoxynBSD changes to Gershwin's session script (contrib/gershwin-system,
Library/Scripts/Gershwin.sh), which LoginWindow runs as the user:
- start the session's sound with /usr/local/libexec/foxyn-audio, which
  foxyn-desktop installs (jackd on OSS, then PipeWire and WirePlumber).
- UTF-8 (LANG=en_US.UTF-8) unless the login class or the user chose a
  locale, as the automatic session's ~/.xsession.
