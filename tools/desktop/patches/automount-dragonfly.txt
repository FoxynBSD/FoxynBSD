FoxynBSD changes to automount (contrib/automount) for DragonFly, which
foxyn-desktop installs for the desktop's removable media:
- the file system type from fstyp(8): file(1) -s blocks reading a disk
  device on DragonFly
- DragonFly's commands: mount_msdos(8), and fsck(8) for UFS
- "automount umassN reap", which devd runs when a USB mass storage
  device detaches: a disk that went away keeps its device nodes while it
  is mounted, so no DEVFS DESTROY event comes; this detaches every
  mounted device that no longer reads
- MOUNT_AS_USER: give the device node and the mount directory to USER
  and mount as USER (vfs.usermount=1; the kernel forces nosuid and
  nodev), so the desktop's file manager can unmount (eject) it without
  privileges; for FAT, a read-only mount by root first loads the kernel's
  character set tables (-D, -L), which only root may load
