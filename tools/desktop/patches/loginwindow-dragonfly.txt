FoxynBSD changes to Gershwin's LoginWindow (contrib/gershwin-components):
- look for XLibre, which tools/desktop/build-xlibre.sh installs in
  /System/Library/XLibre, first;
- DragonFly's struct kinfo_proc uses kp_* field names;
- the X server is started (by foxyn-loginwindow) with a cookie only
  LoginWindow has: grant the user who logs in access to the display by
  user id (localuser) for the session, and withdraw it when the session
  ends.  Upstream's server ran without any working authorization file,
  so every local user could connect to the login screen;
- also end Workspace's ddbd and fswatcher daemons at logout, like gpbs
  and gdnc.
