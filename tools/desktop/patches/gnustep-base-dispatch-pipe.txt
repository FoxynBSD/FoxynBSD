GNUstep Base: drain libdispatch's main queue from the run loop on Unix
systems other than Linux (Source/NSRunLoop.m).  There libdispatch's main
queue handle (_dispatch_get_main_queue_handle_4CF) is a non-blocking
pipe, packed in a 64-bit value: the read end in the high 32 bits, the
write end in the low 32 bits.  NSRunLoop called the function without a
declaration, so the value was truncated to an int, the write end, which
the run loop waited on to become readable: blocks dispatched to the main
queue, and NSOperationQueue's main queue, never ran (Tests/base/NSRunLoop/
dispatch.m, Tests/base/NSOperation/threads.m).  Declare it, watch the read
end and empty the pipe before draining the queue, as the Linux code does
with its eventfd.
