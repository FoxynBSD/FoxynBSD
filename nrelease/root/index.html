Welcome to FoxynBSD

This CD is a FoxynBSD 'Live CD'. Place this in your computer's CD drive before booting, and your computer can boot FoxynBSD from the CD. (If it does not, check that your system firmware boots from CD before it boots from hard drive.)

Log in as 'installer' after the CD boots to install FoxynBSD to your hard drive. The Live CD can also be used as a rescue CD in case of drive failure, or just as a way to run a BSD environment without having to modify a hard drive.

How to get started

FoxynBSD is derived from DragonFly BSD, so the DragonFly installation guide and Handbook apply to it.

FoxynBSD is developed on GitHub: report problems in the issue tracker and ask questions in Discussions.
