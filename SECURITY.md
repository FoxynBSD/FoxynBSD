# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub:
**[Report a vulnerability](https://github.com/FoxynBSD/FoxynBSD/security/advisories/new)**
(Security tab → "Report a vulnerability").

Do not open a public issue, pull request or Discussion for an
undisclosed vulnerability.

Include what you can of the following:

- the affected component (kernel subsystem, driver, utility, library);
- the FoxynBSD commit or branch you tested;
- steps to reproduce, or a proof of concept;
- the impact you believe it has.

## What to expect

FoxynBSD is an early-stage project maintained by a small team. We will
acknowledge a report as soon as we can, keep you informed while we
investigate, and credit you in the advisory unless you prefer otherwise.

## Supported versions

FoxynBSD has no releases yet. Fixes go to the `dev` branch.

## Upstream issues

Much of FoxynBSD's code comes from DragonFly BSD. If a problem also
affects DragonFly BSD, report it to The DragonFly Project as well, or
tell us in your report so we can coordinate.
